## FAQ

### MostlyPDF — free online PDF tools

**Are the PDF tools free?**

Yes — merge, split, rotate, organize, watermark, page numbers and image-to-PDF are free with no sign-up, no watermark and no daily limit.

**Do my files get uploaded and stored?**

Many tools run entirely in your browser, so the file is never uploaded. When a tool needs our servers, the file is sent over an encrypted connection, used only for your task and deleted within 24 hours.

**Is there a size limit?**

The Free plan handles files up to 10 MB per task; Pro raises the limit to 1 GB.

**Can I use the tools through an API?**

API access is available to Pro subscribers — every tool can be called programmatically with keys from your dashboard. A standalone metered API tier is on the way.

**What are the best free PDF tools online?**

Look for tools that are actually free — no daily caps, no watermarks, no forced sign-up. MostlyPDF does the everyday jobs (merge, split, rotate, organize, watermark, page numbers, image to PDF) free in the browser with none of those walls, where most alternatives cap tasks per day or watermark exports.

**How is MostlyPDF different from iLovePDF or Smallpdf?**

The free tier has no ads, no daily wall and no watermark — Smallpdf caps free use at 2 tasks a day and iLovePDF caps batch sizes and shows ads. Pro is a flat $5/month in one currency with a free trial, and includes programmatic API access. See the full comparisons at /vs/ilovepdf and /vs/smallpdf.

### HTML to PDF — free online converter & API

**How do I convert HTML to PDF?**

Paste your HTML (inline CSS welcome) into the tool and press Convert to PDF — you get a paginated A4 document you can download, free with no watermark.

**Is there an HTML to PDF API?**

Yes. The same conversion is available on the MostlyPDF API at a transparent, flat rate — send the HTML with your API key and get back a hosted PDF URL. It is powered by MostlyRender, a Chromium print-to-PDF engine.

**Does it support CSS and page sizes?**

Yes — inline and embedded CSS are rendered by a real headless browser, and you can pick A4, US Letter or US Legal, paginated with print margins.

**Is HTML to PDF free?**

Yes, it is free to start with no sign-up and no watermark; programmatic use is available through the API on the Pro plan.

### Webpage (URL) to PDF — free online & API

**How do I convert a URL to PDF?**

Enter a public web address and press Capture as PDF — the whole page is rendered to a paginated A4 PDF you can download, free with no watermark.

**Is there a URL to PDF API?**

Yes. Send a URL with your API key to the MostlyPDF API and get back a hosted PDF URL, at a flat transparent rate. It is powered by MostlyRender, the portfolio Chromium print-to-PDF engine.

**Does it capture the full page with images and fonts?**

Yes — a real headless browser loads the page, so images, web fonts and CSS layout are preserved across A4, US Letter or US Legal pages.

**Is Webpage to PDF free?**

Yes, it is free to start with no sign-up and no watermark; programmatic use is available through the API on the Pro plan.
